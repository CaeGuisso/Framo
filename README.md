# Framo

**Um novo jeito de criar e editar vídeos.**

O Framo é um projeto de editor de vídeo que estou desenvolvendo com o objetivo de criar uma experiência moderna, intuitiva e acessível para edição de vídeos.

A ideia é construir uma interface inspirada nos editores profissionais, com foco em usabilidade, organização e ferramentas que facilitem o processo de edição.

## Sobre o projeto

O Framo nasceu como um projeto pessoal para transformar uma ideia em uma aplicação real, explorando o desenvolvimento de interfaces e, futuramente, a implementação de recursos de edição de vídeo.

Mais do que criar um editor, o objetivo é aprender, experimentar novas tecnologias e desenvolver uma aplicação cada vez mais completa.

## Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/CaeGuisso/Framo.git
```

Entre na pasta:

```bash
cd Framo
```

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
